A busy week. Security and breaking changes first, because two of them matter if you ship agents behind a UI.

Breaking changes and security

Security · Pydantic AI

AI Engineering · Guardrails

Pydantic AI: three advisories fixed

Three advisories fixed. High: web_fetch could stall the process on hostile HTML (fixed in 2.59.0 / 1.107.9). Medium: MCP config could leak server URLs and auth tokens into OpenTelemetry traces, and the Vercel AI / AG-UI adapters could run a tool with client-chosen arguments (fixed in 2.58.0). Upgrade, then rotate any tokens that may sit in old traces.

v2.58.0https://github.com/pydantic/pydantic-ai/releases/tag/v2.58.0 v2.59.0https://github.com/pydantic/pydantic-ai/releases/tag/v2.59.0

Breaking · Google ADK

AI Engineering · Measure

Google ADK 2.13.0 telemetry schema

Telemetry now defaults to the newer OpenTelemetry GenAI schema and drops the call_llm span, so dashboards built on it will go quiet. Set ADK_TELEMETRY_SCHEMA_VERSION_OPT_IN=otel_semconv_1_36 to keep the old one. It also requires authlib 1.9.1+ for CVE fixes.

Releasehttps://github.com/google/adk-python/releases/tag/v2.13.0
