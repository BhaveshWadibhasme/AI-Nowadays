Case study · LangChain internal

Inside LangChain’s design agent: 3,000+ assets on Managed Deep Agents

Amal Irgashev (GTM Agents @LangChain) says the company's design agent has shipped over 3,000 assets and posts whose work pulled more than 4.5M views on socials. It handles decks, diagrams, ad creatives and launch films, all requested in Slack, and three in four requests now come from outside marketing.

The team encoded their brand designers' judgment into the agent's skills, a design wiki and brand checks that run on every render, and built a custom media harness around it: a headless Photoshop, a shared visual canvas with Paper, video tools like Hyperframes from HeyGen plus their own animation engine, brand assets and a library of design references. It runs on Managed Deep Agents, and their own code shrank by about 80% after migrating. A live walkthrough is on Oct 28 at 11am PT, and the full blog post and open-source repo are due next week.

Why it matters

A concrete template for an internal “service desk” agent: encode expert judgment as skills plus automated checks, give it domain tools, and let a managed runtime handle sandboxes, memory and Slack. That is exactly the pattern a department AI consultant can pitch.

Case study · Security

Corridor’s Argos: a fine-tuned 9B security model built from traces

Corridor used smithtune's trace-based workflow to build the training data for Argos, a fine-tuned 9B model that scored highest of the 14 models they tested on their security context benchmark. Argos reads a coding agent's plan and selects codebase-specific security guidance before implementation, so the requirements become part of the plan the agent codes from.

Corridor fine-tuned it using Baseten Loops; it returns a complete selection in 2.5 seconds on average. Their post covers how they built Argos, evaluated its selections, and used LangSmith to inspect the security context agents receive in production.

Why it matters

Following the 19 Oct theme of agent traces as training data, this is a real result: a small specialist model trained on traces beating frontier models on one narrow step, at lower cost and latency.

A vision deep agent that turns hand-drawn railway plans into CAD

LangChain collaborated on a post by Gregor Beuster (Member of Technical Staff, DB Engineering & Consulting), whose LangChain Interrupt 2026 talk from London is now on YouTube. It shows how a vision deep agent converts hand-drawn railway plans to CAD files using only 2 core tools.

Explainer · Deep Agents

How Deep Agents keeps long contexts from hurting reasoning

The more history and tool output a model carries, the worse its reasoning gets. Deep Agents handles this two ways. Offloading: when a tool result comes back huge, like a 20,000 token database query, it's saved to a virtual file system and the model only sees a preview, paging through the full result with the read file tool if needed.

Summarization: once the context window hits 85% (a default you can change), older messages are condensed into a summary so the agent has room to keep working, and nothing is deleted. Jess Weng explains it in a short video, and there's an Agent Memory 101: Context Engineering session to sign up for.

Why it matters

Two simple, tunable defaults worth copying in any agent that queries databases or calls chatty tools, even outside Deep Agents.
