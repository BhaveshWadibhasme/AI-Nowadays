Google launches Gemini Decision 1, a model built only for picking answers

A new Decisions API scores yes/no, multiple-choice (up to 255 options) and rubric questions in a single pass instead of generating text. Up to 1,000 questions per request, 256K context, answers in about 150–250 ms with a confidence score, at $0.10 per million input tokens and nothing for output. LangChain shipped day-zero support. Independent tests from Artificial Analysis were more mixed: tied with rivals on their Decision Index and slower than TypeSafe's Jev.

Why it matters

Classification, routing, triage and LLM-as-judge scoring are a big slice of enterprise workloads. A purpose-built decision model can cut cost and latency sharply versus asking a chat model to “answer with one word”, and the confidence score helps with thresholds and human review.

Google bloghttps://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/

Cloudflare's hybrid agent pattern: fast models choose tools, one big model diagnoses

At the AI Engineer CODE summit, Cloudflare showed an agent where fast decision models handle tool selection and log extraction, and a large reasoning model is called only for the final diagnosis. In their demo this cut six LLM calls to one and about 40K tokens to 1.8K.

Why it matters

A concrete, copyable architecture for cutting agent cost: put cheap models on the “which tool / which field” steps and save the expensive model for the one step that needs real reasoning.

Claude Fable 5.2 tops the leaderboards: cheaper per token, pricier per task

Anthropic released Claude Fable 5.2 and Mythos 5.2, now #1 on most independent leaderboards. Price fell 20% to $8/$40 per million input/output tokens, but SemiAnalysis paid $88.15 per task on its professional-task benchmark versus $67.16 before, because the model wrote hundreds of tests and spun up subagents to check itself. Anthropic and Vals both found the “high” effort setting often matches or beats “max” at about half the cost. Fable 5.2 also requires data retention by default; zero retention is only for eligible enterprise customers.

Why it matters

Token price is not task price. Measure cost per successful task on your own evals before switching models, and test lower effort settings first. The data-retention default is a real procurement question for regulated firms.

AI Engineering · Guardrails

“Don't ask again” in Claude Code wrote 2,539 real secrets into public GitHub repos

Apiiro found that approving a command with “Yes, and don't ask again” saves the exact command, secret included, to .claude/settings.local.json. Across public repos it counted 2,539 secrets in 1,994 repositories, including 379 database passwords and 23 AWS keys; many were missed by common secret scanners. Advice: search for that file across your org, check git history, rotate first, use environment variables like $DB_URL, and approve command patterns rather than literal commands.

Why it matters

Approval fatigue is a real security risk with coding agents. If your team uses Claude Code or similar tools, this is a five-minute audit worth doing this week.

LinkedIn articlehttps://www.linkedin.com/pulse/claude-code-leaked-2539-passwords-genai-works-o5nqf

AI Engineering · Guardrails

Zero-trust agent systems that pass audits and still ship (InfoQ talk)

Advait Patel's playbook moves security from the prompt to the tool layer: give each agent a workload identity, use short-lived scoped tokens per tool, treat tool outputs as untrusted (the main prompt-injection path), enforce access controls in retrieval, keep identity-linked traces as audit evidence, and pre-build kill switches.

Why it matters

A clear checklist for getting agent pilots past security and compliance review in an enterprise like bp.

InfoQ talkhttps://www.infoq.com/presentations/zero-trust-ai-agents-production-security/

AI Engineering · Measure

Coding agents: a 30x spread in cost per task among the top performers

Artificial Analysis updated its Coding Agent Index to harder benchmarks; Fable 5.2 and Opus 5.5 tie at the top. Among setups scoring 48 or more, cost per task ranges from $1.51 (Codex with GPT-6.1 Sol) to $44.22 (Fable 5.2 at max), and Fable at medium, high and extra-high all sit on the best value curve.

Why it matters

When recommending a coding agent, cost per task can vary 30x for similar quality. Benchmark on your own repos and report cost alongside pass rate.

Gemini 4 Carbon and Hydrogen: Google pairs a planner model with a fast doer

Google released Gemini 4 Carbon (its strongest model for long agentic work) and Gemini 4 Hydrogen (a speed-first tier at $1.50/$7.50 per million tokens with a low hallucination rate in independent tests). In Antigravity's new orchestrator mode, Carbon plans while Hydrogen writes and tests code, reaching near-Carbon results with 24% less quota and 19% faster completion. Testers flagged slow first-token times for Carbon.

Why it matters

Planner/executor splits are becoming a built-in product feature, not just a DIY pattern. Same lesson as Cloudflare: mix models by role.

LlamaParse drops usage caps and documents running in your own cloud
