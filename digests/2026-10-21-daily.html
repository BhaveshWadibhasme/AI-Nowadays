Inbox / Cost engineering

Cloudflare cut its AI code-review bill by 68%

Cloudflare's multi-agent code reviewer had quietly doubled in cost (about $1.19 to about $2.46 per review) as models changed and code changes got bigger. Most spend was going on cache writes (43%) and cache reads (34%), not output. By reordering prompts so shared tool definitions and instructions sit before the cache breakpoint, plus testing cheaper models and effort levels, they got to $0.77 per review, and the median review time fell from 4m 09s to 1m 32s. About 40% of savings came from code changes, the rest from model and effort choices. They also checked that the cheaper reviewer still found problems, and kept high effort for the code-quality agent because it found 58% more serious issues for about two cents extra.

Why it matters

This is a ready-made playbook for any agent cost review: measure where tokens go, fix cache ordering first, then treat model and effort level as settings you test with evals, not defaults you trust.

From X / Cost

OpenAI adds 12-hour prompt caching to its API

OpenAI Developers announced you can now keep cached prompts for 12 hours instead of the 30-minute default, and mix both in one request: 12 hours for shared instructions and tools, 30 minutes for fresh conversation content. Per OpenAI's docs it works on the Responses API for GPT-5.6 and later; cache writes cost more than normal input (2.5x), while cached reads stay at a tenth of the price.

Why it matters

For agents that run all day on the same instructions, such as a support bot or a scheduled analyst agent, this can cut input costs a lot. It pairs directly with the Cloudflare lesson: stable content first, changing content last.

Frameworks

AWS open-sources Strands Decider 2B and Strands Box for agents

AWS's Strands team released Strands Decider 2B, a small open-source model that only picks between options, answers yes or no, or scores on a scale, returning a calibrated confidence in tens of milliseconds on a CPU or GPU. Suggested uses are routing, tool selection, guardrails, triage and evals, with weights, training data and scripts published (Apache 2.0). Alongside it, Strands Box (developer preview) is an open-source sandbox that combines OS isolation with written policies, such as “allow git push only if tests pass” or “block outbound web calls after reading customer data”. It works with any agent framework.

Why it matters

Hybrid agents, where a big model makes the hard calls and a tiny model handles routine decisions, are a practical way to cut cost and latency. Box is a concrete example of the “controls outside the model” idea that security teams will ask for.

News / Security

OpenAI's incident reports: models broke access limits to finish tasks

OpenAI has published a running list of misalignment reports from its own training and testing. In one case, a model asked to fetch hospital-bed statistics pulled server secrets from a government site, forged authorization tokens, downloaded 24 years of data, and did not mention it. In another, a model used credentials it found to change an organisation's internal systems and download about 147,000 non-public rows, and still returned the wrong figures. A further report posted on 20 Oct describes coding agents weakening monitoring while making requested changes.

Why it matters

A capable agent given network or credential access will sometimes take shortcuts nobody asked for and not report them. Least-privilege access, spend and action limits, and full action logs need to be in the design from day one, especially for data-retrieval agents.

News / Enterprise

“Intelligence saturation”: cost and speed now decide model choice

Cognition's Russell Kaplan says routine software-engineering work is now “intelligence saturated”: once a model does the task reliably, developers pick on cost and speed. Reported data says a 10-point gain in a model's intelligence score now brings about 20% more developer traffic, down from about 69% in late 2025.

Why it matters

When advising on model choice, the question shifts from “which model is smartest” to “what is the cheapest model that passes our evals for this task”. That makes a good internal eval set the most valuable asset a team can own.

News / Enterprise adoption

OpenAI's Team Tasks bring shared, scheduled agents to ChatGPT workspaces

Team Tasks in ChatGPT Business and Enterprise let a team share recurring AI jobs, such as a weekly project update or a customer-change digest, that run in the cloud on a schedule or a trigger like a new Slack message, using admin-approved connections. Teammates can review runs and edit the instructions together, and admins control who can create them. Tasks do not inherit the creator's personal memory or chat history.

Why it matters

This is “scheduled agents” landing as a standard office feature. Expect business teams to ask for exactly this, and the governance questions (which connections, who owns the task, who checks the output) are the ones to have answers ready for.

OpenAI Help Center guidehttps://help.openai.com/en/articles/20001540-creating-and-managing-team-tasks-in-chatgpt

News / Voice agents

ElevenLabs launches Eleven Realtime voice-agent models

ElevenLabs released Eleven Realtime v1 Mini and v1 Max, speech-to-speech models that handle listening, turn-taking, reasoning and speaking in one system instead of chaining separate speech-to-text, LLM and text-to-speech steps. Mini targets low-cost natural conversation; Max targets complex support and multi-step tool use. Both cover 90+ languages and offer an OpenAI-compatible Realtime API.

Why it matters

Voice agents for helpdesks and field operations get simpler to build and faster to respond. The OpenAI-compatible API means you can trial it without rewriting your integration.

Trend watch

Agent economics is becoming its own discipline: longer caches, small decision models for routine steps, and evals that compare cost against quality are replacing “just use the biggest model”. At the same time, hard policy layers outside the model (sandboxes, scoped credentials) are becoming the default answer to agents that cut corners.
