Course · DeepLearning.AI

Loop Engineering with LangChain Deep Agents: a free course

DeepLearning.AI launched a free course, built with LangChain and taught by Sydney Runkle and Esmaeil Gargari, on building agents you can rely on for long, complex tasks like building software. Its premise: an agent that finishes a task hasn't necessarily done it well.

It teaches four loops that make an agent dependable: an agent loop that calls tools and observes results to complete multi-step tasks; a verification loop that checks the agent's work and sends feedback for a retry; an event-driven loop that triggers runs from external events; and a hill-climbing loop that improves the harness using past traces. Sydney Runkle (Product at LangChain) added that the course, made with Andrew Ng and Esmaeil Gargari, focuses on agents that handle complex tasks and improve over time with Deep Agents.

Why it matters

A free, structured path through the exact patterns behind production agents: verification, event triggers and trace-driven improvement. It's a quick way to build credible hands-on depth for consulting and FDE-style work.

Research · Agent memory

Evidence-grounded agent memory with OpenWiki and graphs

Agents working across policies, manuals, tickets and code have to work out which rules apply and what has changed, and without memory they often rebuild that understanding on every question. Eugene Liu on the LangChain team paired OpenWiki, LangChain's open-source wiki compiler, with a lightweight evidence graph: the wiki synthesizes source material into reusable knowledge, while the graph gives agents explicit paths to supporting passages and related documents.

On complex, domain-specific questions requiring cross-source reasoning, they saw 5x higher accuracy with the compiled wiki compared to grep-based search alone, a further 27% improvement in accuracy when the evidence graph was added, and 2x citation consistency with 58% lower cost per correct answer using the graph compared to the wiki alone.

Why it matters

This hits two pillars at once, giving the agent context and cutting the cost. For enterprise knowledge work over policies and manuals, traceable citations plus lower cost per correct answer is exactly the case stakeholders want to see.

Product · Managed Deep Agents

70%+ of Managed Deep Agent runs are now driven by schedules

Since dynamic scheduling for agents launched in September, more than 70% of all Managed Deep Agent runs on LangSmith are driven by schedules rather than human interaction.

Examples LangChain gives: reporting agents that update documents and post sales readouts or KPI updates to Slack or email on a schedule; monitoring agents that watch traces and alert on outages; assistants that track incoming emails, calendars or Slack messages and escalate what you missed; and self-improving agents that open PRs against themselves based on failure modes found in trace scanning. Nathan Drezner wrote a deep dive on how it works and how to use the Schedules SDK in a Managed Deep Agent.

Why it matters

Most agent work in production is now proactive, not chat. Scheduled reporting and monitoring agents are among the easiest, highest-value use cases to pitch inside a department.

Design agent · Content Studio

Deslopifying the design agent

LangChain reshared Amal Irgashev (GTM Agents at LangChain): a better prompt won't fix AI slop. Without your context, a model fills every open decision with whatever pattern it's seen most, so everything starts to look the same. What worked was sitting with their designers, writing down everything they notice, and turning that into context the design agent uses on every render, with daily iteration in Slack.

To show it, Shreya Talegaonkar's idea was to give Content Studio the generic AI version of its own work and ask it to "deslopify" it; every edit in the video is a real rule it learned from the team. The post promoted the live session on Oct 28 at 11am PT (covered on yesterday's page). LangChain also reshared its inside look at how it built Content Studio, the open-source design agent in Slack that makes on-brand videos, graphics and decks, and the harness that powers it.

Why it matters

Encoding expert judgment as reusable context, rather than longer prompts, is the practical fix for generic agent output in any domain, from slides to analysis reports.
