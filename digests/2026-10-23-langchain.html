Event · Workshops · Chicago

LangSmith Roadshow: Building Agents with Agents — Chicago

The next stop on the LangSmith Roadshow is Chicago. The event opens with the current state of agent development, then moves into two hands-on workshops. Agent harnesses with Deep Agents explores the core concepts behind agent harnesses and how to build with Deep Agents. Improving your agents with LangSmith Engine is a hands-on session with an agent for agent engineering that identifies where your agent is failing and helps make the fix for you.

LangChain says the event is designed for agent engineers, AI platform teams, and technical leaders building and operating agents in production. The post doesn't give a date; RSVP details are on the event page.

Why it matters

LangChain keeps using Deep Agents harnesses and LangSmith Engine as its hands-on curriculum: build the agent, then use an agent to find where it fails and fix it. Even without attending, those two workshop topics are a good outline for how a department AI consultant or future FDE could structure an agent pilot in Pune: a sound harness first, then a repeatable loop for finding and fixing failures in production.
