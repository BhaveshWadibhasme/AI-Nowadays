Anthropic: fold your subagents back into one agent loop

Anthropic's Applied AI team published guidance, based on enterprise deployments, that a single agent loop which loads skills and tools on demand often beats orchestrator-plus-specialist designs on quality, cost and latency. One customer's single loop ran about twice as fast. Keep subagents only for real parallel work, proven context overload, or very large tool sets (tool choice gets worse past roughly 30 to 50 tools). They released a migration kit that folds one subagent at a time and keeps it only if the shared eval says the merged version holds.

Why it matters

If your department is designing agents around team boundaries, this is a strong, evidence-backed argument for fewer handoffs. The “measure, combine, fold” method is a ready-made consulting playbook.

Cursor's Agent SDK is generally available

Cursor released the Agent SDK it uses for its own agents like Bugbot. An agent is a project folder: instructions in Markdown, each tool a typed TypeScript file, skills loaded on demand, MCP connections, and built-in evals that check which tools ran and what the reply looked like. Deploy to Cursor's hosting with one command or run it yourself as a Node process.

Why it matters

“Agents as code with evals in CI” is becoming the default shape for production agents, so treat prompts and tools like versioned, tested software.

Cursor announcementhttps://cursor.com/blog/agent-sdk

Agent S4: let agents build the tools they were missing

Simular's Agent S4 paper has a meta-agent read past run traces and write reusable tools, such as bulk-editing a spreadsheet range instead of clicking cell by cell. Tool versions are chosen on separate validation tasks. With the same Qwen model, success on OSWorld V2 reached 21.3% (about 3.8 times the fixed-tool baseline), and ScienceBoard went from 41.4% to 58.6%.

Why it matters

When an agent is slow or clumsy, the fix is often a better tool, not a better prompt. Reviewing traces for repeated busywork is a practical habit to adopt.

Paper on arXivhttps://arxiv.org/abs/2610.28601

Running DeepSeek V4.1-Flash locally on a 128GB machine

DeepSeek's V4.1-Flash-1017 update (MIT-licensed, 1M-token context) improved coding and agent benchmarks. Unsloth's smallest 1-bit build runs on a 128GB-class machine by keeping a large lookup-table part of the model on SSD. The trade-off: the tiny build picks the same next token as the full model only about 83 to 85% of the time.

Why it matters

Strong open models on a single workstation are an option for sensitive data or cost-capped pilots, but heavy quantization changes behaviour, so evaluate the exact build you deploy.

Unsloth setup guidehttps://unsloth.ai/docs/models/deepseek-v4.1-flash

AI Engineering · Measure

15 reliability targets (SLOs) for an AI agent

Tanmay Deshpande defines 15 agent service-level indicators as simple good-events over valid-events ratios: did the task finish, was it correct, did tool and model calls work, was working memory accurate. He shows which ones OpenTelemetry captures out of the box and which need custom instrumentation.

Why it matters

It moves agent monitoring beyond token counts and latency toward what operators and business owners actually care about, and gives you a template to propose.

Article on Mediumhttps://medium.com/data-science-collective/i-built-15-slos-for-an-ai-agent-heres-what-opentelemetry-could-measure-dcbacf4c3e9e

Oracle: describe the goal, let Fusion Companion route the work

At Oracle AI World, Oracle announced Fusion Companion and Fusion Agentic Home. Users state a business goal and Companion picks the transactions, workflows, approvals and agents across finance, HR, supply chain and more, within existing permissions, and can be reached from tools like ChatGPT. No pricing or general-availability date was given.

Why it matters

Big ERP vendors are turning agents into an orchestration layer over existing approvals and permissions, which is the pattern to expect in large energy and industrial firms too.

Oracle announcementhttps://www.oracle.com/news/announcement/ai-world-oracle-introduces-new-ai-powered-ways-to-execute-work-across-oracle-fusion-applications-2026-10-26/

Where's the payoff outside Big Tech?

An analysis by Apollo economist Torsten Slok, widely discussed on X, found revenue per worker and margins rising for the seven largest tech firms but flat for the other 493 S&P 500 companies, with mainstream firms starting to treat AI token spend as a cost rather than a growth driver. Skeptics note aggregate numbers may miss early gains.

Why it matters

Expect harder ROI questions from leadership. Pilots that track measurable business outcomes will get funded; vague productivity claims won't.
