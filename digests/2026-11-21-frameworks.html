A busy week: two security fixes and four releases with breaking changes. Here's what matters in practice.

Breaking changes and security

Security · Pydantic AI

AI Engineering · Guardrails

Pydantic AI Harness — 2 high-severity fixes

Two regex patterns could freeze the event loop for minutes on crafted input: strip_ansi=True in ToolOutputLimits, and the default jwt pattern in redact_secrets. If tools handle text from outside users, upgrade to pydantic-ai-harness 0.70.0.

v2.70.0 noteshttps://github.com/pydantic/pydantic-ai/releases/tag/v2.70.0

Breaking · Google ADK

AI Engineering · Guardrails

Google ADK Python 2.15.0

The Visual Agent Builder is gone from ADK Web (agents you built with it are still standard YAML). McpInstructionProvider no longer passes session.state to MCP servers automatically, a security hardening change, so pass arguments= yourself.

Releasehttps://github.com/google/adk-python/releases/tag/v2.15.0

Breaking · OpenAI Agents SDK

AI Engineering · Tools + agents

OpenAI Agents SDK 0.25.0

The beta Runloop sandbox is removed, and the checkpoint format changed. If workers share checkpoints, upgrade the readers first. Compaction now defaults to gpt-6-luna.

Releasehttps://github.com/openai/openai-agents-python/releases/tag/v0.25.0

Breaking · Claude Agent SDK

AI Engineering · Tools + agents

Claude Agent SDK (TypeScript) 0.3.327

Hook options must now be arrays, and query() rejects options it can't serialise.

Releasehttps://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.327

Security · CrewAI

AI Engineering · Guardrails

CrewAI 1.15.42–1.15.44

Raises the soupsieve floor for CVE-2026-126190 and enforces working-directory containment on all FilePath paths.

1.15.42https://github.com/crewAIInc/crewAI/releases/tag/1.15.42 1.15.44https://github.com/crewAIInc/crewAI/releases/tag/1.15.44
