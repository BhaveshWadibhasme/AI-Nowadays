Security · Pydantic AI

AI Engineering · Guardrails

Pydantic AI 2.66.0 / 1.107.10

Fixes two high issues: web_fetch_tool / local WebFetch could explode deeply nested JSON into huge memory use before size limits applied, and Harness secret redaction’s private_key pattern could hang the event loop. Medium fixes cover a missing Tencent Cloud metadata IP and OTEL embedding header leakage. Upgrade if you fetch URLs or redact secrets.
