Security · CrewAI

Patches deserialization, SQL injection and path traversal bugs, including a path traversal in output_file via template interpolation. Go straight to 1.15.33.

Breaking · Microsoft Agent Framework

AI Engineering · Guardrails

Microsoft Agent Framework (Python 1.24.0)

Breaking change in agent-framework-redis: context scopes are now case-sensitive and legacy indexes get rejected, so check Redis memory before upgrading. It also blocks metaclasses during checkpoint restore.

Python noteshttps://github.com/microsoft/agent-framework/releases/tag/python-1.24.0

Breaking · Microsoft Agent Framework

AI Engineering · Tools + agents

Microsoft Agent Framework (.NET 1.27.0)

Two breaking changes. Foundry hosting moves to builder.AddFoundryResponses(...), and old local response files aren't read after upgrading. Redirect callbacks must now return null or throw.

.NET noteshttps://github.com/microsoft/agent-framework/releases/tag/dotnet-1.27.0

Breaking · Mastra

AI Engineering · Tools + agents

Mastra core 1.80.0

queryTraceThreads() drops model and provider and caps page size at 100. Connect sessions return launchUrl instead of connectUrl, and Code SDK no longer registers built-in subagents by default.

noteshttps://github.com/mastra-ai/mastra/releases/tag/%40mastra/core%401.80.0

Worth knowing

Pydantic AI

AI Engineering · Guardrails

Pydantic AI 2.62 to 2.64

A lot of production-ready features landed. You get provider batch APIs, a DetectLoops capability that stops agents repeating themselves, PostgresSpendStore for shared budget limits, sticky ModelFallback, and an ArtifactScanner that checks memory and skills for risky content.

v2.64.0https://github.com/pydantic/pydantic-ai/releases/tag/v2.64.0 v2.63.0https://github.com/pydantic/pydantic-ai/releases/tag/v2.63.0 v2.62.0https://github.com/pydantic/pydantic-ai/releases/tag/v2.62.0

LangGraph

AI Engineering · Tools + agents

LangGraph 1.2.18 and 1.2.19

error_handler can now recover on every path. Delta snapshots now happen every 100 updates instead of 1000, so reads are faster but storage use goes up. The Python SDK reconnects streams with backoff.

1.2.18https://github.com/langchain-ai/langgraph/releases/tag/1.2.18 1.2.19https://github.com/langchain-ai/langgraph/releases/tag/1.2.19

Mastra

AI Engineering · Measure

Mastra 1.80.0

Each end user can now connect their own OAuth accounts, there's a span-aggregation API for cost and latency metrics, and provider errors are sorted into clear types such as rate limit, quota and context overflow.

Agno

AI Engineering · Tools + agents

Agno 3.1.11 and 3.1.12

ClaudeAgent and CodexAgent can now join Agno Teams and Workflows, with native approvals in the AgentOS UI. Heads-up: AccuracyEval's old default judge used o4-mini, which OpenAI shut down on Oct 23, so set your own judge model.

Worth trying
