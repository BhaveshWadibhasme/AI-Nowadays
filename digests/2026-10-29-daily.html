Artificial Analysis Intelligence Index v5: mostly private tests, with cost per task in plain view

60% of the index now comes from private or held-out test sets. It adds FrontierCode 2.0 and Terminal-Bench-Science, and it drops GDPval-AA, SciCode and AA-LCR. Claude Opus 5.5 scores 58, GPT-6 Astra 57, GPT-6.1 Sol 55 and Gemini 4 Argon 50. Among the top 10, GPT-6.1 Terra costs $0.96 per task and Claude Fable 5.1 $13.04. The gap between the best open-weight and closed models widened from 3 points to 12.

Why it matters

Public benchmark scores are easier to game, so held-out tests and cost per task are better guides when you pick a model for a client. A 13x cost gap between top models is a strong argument for routing work to the cheapest model that passes your own evals.

DeepSeek open-sources DeepInfer, the inference engine behind its production service

DeepInfer is Apache-2.0 and runs DeepSeek V4.1-Flash. It overlaps CPU batch scheduling with GPU work, uses speculative decoding (a small draft guesses tokens ahead and the main model checks them), and has a batch-invariant, deterministic mode so the same request gives the same answer whatever else is in the batch. It targets NVIDIA SM100 GPUs and Huawei Ascend 950, and leaves out KV-cache management, disaggregated serving and load balancing.

Why it matters

It's a readable reference for where latency and cost actually go in serving. The deterministic mode also matters for evals, because it lets you tell a model change apart from a runtime change.

DeepInfer on GitHubhttps://github.com/deepseek-ai/DeepInfer

AI Engineering · Guardrails

Guardrails quietly break when the embedding model changes underneath them

An InfoQ panel of five practitioners shared a banking case. A guardrail blocked investment-advice questions by comparing them with stored examples using embeddings. It worked for two weeks, until an automatic update meant the questions and the examples were embedded by different models. Valid requests got blocked and others got through. The panel also suggested mutation testing to check whether tests catch wrong behaviour, and turning red-team findings into repeatable tests. The source was an InfoQ webinar recap email with no public page.

Why it matters

Pin the embedding model, record which model built your example store, and rerun a fixed allow/block test set after every model or library update. This is a cheap habit that prevents a silent failure.

InfoQ AI, ML and data engineeringhttps://www.infoq.com/ai-ml-data-eng/

Flint, an open coding model you can run locally

Recursive released Flint, a 39.8B-parameter coding model with about 2.5B active per token, a 256K context window, tool calling and Apache-2.0 weights. Unsloth's 3-bit build is 18.5GB, so it runs on a 24GB machine at short contexts and can plug into coding agents. Reported scores are 74.2% on SWE-bench Verified and 54.9% on Terminal-Bench 2.1, for the full-precision model.

Why it matters

It's a realistic option for coding agents where code can't leave the building. One practical tip from the guide: if you build your own client, keep the model's reasoning and tool-call messages in the conversation history, or multi-step tool use degrades.

Unsloth guide to running Flinthttps://unsloth.ai/docs/models/flint

Anthropic shares numbers from six drug-development partnerships

Scientists at Generate Biomedicines used Claude Code to redesign part of a CAR-T cancer therapy. One design was about 70% shorter and, in lab tests, produced roughly 10 times as much of the protein immune cells use to find cancer. It hasn't been tested in animals or people yet. At Enveda, a manufacturing review dropped from 25.9 hours to 2.8 and caught 7 problems human reviewers missed.

Why it matters

These are concrete before-and-after numbers from regulated, document-heavy work, the kind of evidence that helps when you pitch AI use cases in a large company like an energy major.

An Anthropic hiring manager drops the coding interview

Felix Rieseberg says he removed coding interviews from his Anthropic team's hiring loops this month because they no longer give a useful signal. His advice for early-career engineers: pick business impact over the backlog, build a working prototype over a weekend, and focus each prototype on one good idea.

Why it matters

This is close to a Forward Deployed Engineer job description. Hiring is moving toward people who can spot a business problem and ship a working prototype quickly.
