Product · LangSmith

LangSmith Agent Platform, Tool Gateway, trace controls and AI Search

LangChain introduced the new LangSmith Agent Platform, described in "Why we rebuilt LangSmith around the agent". Jess Weng recapped the week: the platform, new trace controls for sensitive data, LangSmith for Coding Agents (which ties agent spend to pull requests) and the LangSmith Tool Gateway.

LangSmith Tool Gateway is a managed tool layer for credentials, identity and access on every agent tool call, in Public Beta. Trace controls in LangSmith Enterprise let teams restrict trace inputs and outputs, manage access by team groups and set ABAC policies from metadata. LangSmith AI Search can now parse plain-language queries into structured filters and asks follow-up questions when a query is vague. A new coding-agent dashboard shows cost by model, GitHub user and PR status, plus the 20 most expensive PRs.

Why it matters

Governance of tool access, trace data and agent spend is moving into the observability platform itself, which is what enterprise rollouts ask for.

Data · LangSmith Signal

LangSmith Signal: which models production agent teams use

LangChain published LangSmith Signal, a data post built from billions of agent runs. It reports gpt-6-luna (launched 22 Sept) now at #1, used by 27% of production teams; claude-sonnet-5-5 and gpt-6.1-sol entering at #5 and #6, each used by 22% of teams; and gpt-5.6-luna still handling the most LLM calls, at 13%.

Why it matters

Real usage data across production agents is a more grounded signal for model choice than benchmark leaderboards.

Case study · GTM agent

GTM Agent results and the Clay rebuild on the Max Agency podcast

LangChain shared results from its own GTM Agent: deals with a GTM Agent artifact moved to a later stage 47% of the time, against 16% without one, across 1,540 artifacts in 12 weeks and 337 rep-hours saved.

Season 2 of the Max Agency podcast is back, with Harrison Chase talking to Clay Head of AI Jeff Barg about rebuilding their GTM agent.

Why it matters

Rare quantified outcomes for a sales agent, useful as a template for how to measure agent impact.
