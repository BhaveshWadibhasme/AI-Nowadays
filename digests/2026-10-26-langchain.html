Blog · Context engineering

Context engineering for AI agents starts with retrieval

LangChain asks how agents remember to retrieve the right info at the right time, and points to its top retrieval strategies. The blog says retrieval breaks in three ways: inefficient searching, too much context at once, and irrelevant or stale context.

Using a competitive analysis agent as the example, it shows how the Deep Agents harness keeps searches small out of the box: glob matches file names, grep finds matching lines, and read_file reads a page at a time, while oversized tool results are offloaded to files with only a path and preview returned. For custom search tools like RAG, the recipe is “retrieve, offload, delegate”: save results to files, return the paths, and let subagents read them, adding a semantic retrieval tool when keywords aren't enough and letting the agent decide when to search.

Why it matters

A practical checklist for any RAG or research agent you build at work: search before you read, never dump a whole export into context, and push heavy reading to subagents so the main agent only sees what matters.

Talk · Learning Loop event

Will Brown: continual learning is about to get boring, in a good way

At LangChain's recent Learning Loop event, Will Brown from Prime Intellect made the case that “we're all in post-training college right now,” and that soon updating your model's weights will feel as routine as shipping software. The full session is available to watch.

Why it matters

Trend watch

The weekend's posts circle one question: how an agent gets the right information at the right time. In the short run that's context engineering, with search-before-read filesystem tools, offloading big results to files and delegating reading to subagents. In the longer run it's continual learning, where what the agent learns flows back into the model's weights through routine post-training. Together with Friday's trace-trained models, the direction is clear: agents improve by managing context well today and by learning from their own runs tomorrow.
