The last three days were about agents getting more organized and closer to production. A new frontier model arrived for long agentic jobs, Anthropic launched multi-agent orchestration, and security patching in the MCP ecosystem now matters as much as new features.

Models

Meta's Muse Wonder puts Meta back near the top.

Artificial Analysis scores Wonder Full at 56, behind only Opus 5.5 at 58. It made big agentic gains (Terminal-Bench went from 33% to 57%), costs $4 per million input tokens and $20 per million output, and has a 1M-token context window. It's API-only, unlike Llama.

Why it matters

The old 'Meta means open weights' story no longer holds for build-vs-buy and data residency advice.

Agents

Anthropic's dynamic workflows for Claude Managed Agents

These workflows use layers of trusted maintainers, like Linux, so the human isn't the bottleneck.

Why it matters

It explains why big agent projects need an org chart of agents, not one huge prompt.

Latent Spacehttps://www.latent.space/p/claude-dynamic-workflows

MCP

MCP got ten security advisories, and two fixes are off by default.

The worst (CVSS 7.5) let a malicious server steal a client's OAuth secrets. You need Python mcp 1.30.0/2.2.0+ or TS SDK 1.32.0/2.3.0+, and you have to enable the token-audience checks.

Why it matters

Upgrading alone doesn't close the hole.
