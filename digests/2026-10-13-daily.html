Daily AI Digest: Tue, 13 Oct 2026

The last three days were about agents getting more organized and closer to production. A new frontier model arrived for long agentic jobs, Anthropic launched multi-agent orchestration, and security patching in the MCP ecosystem now matters as much as new features.

  • Meta's Muse Wonder puts Meta back near the top. Artificial Analysis scores Wonder Full at 56, behind only Opus 5.5 at 58. It made big agentic gains (Terminal-Bench went from 33% to 57%), costs $4 per million input tokens and $20 per million output, and has a 1M-token context window. It's API-only, unlike Llama. Why it matters: the old 'Meta means open weights' story no longer holds for build-vs-buy and data residency advice. https://www.latent.space/p/ainews-meta-muse-wonder-and-wonder
  • Anthropic's dynamic workflows for Claude Managed Agents use layers of trusted maintainers, like Linux, so the human isn't the bottleneck. Why it matters: it explains why big agent projects need an org chart of agents, not one huge prompt. https://www.latent.space/p/claude-dynamic-workflows
  • MCP got ten security advisories, and two fixes are off by default. The worst (CVSS 7.5) let a malicious server steal a client's OAuth secrets. You need Python mcp 1.30.0/2.2.0+ or TS SDK 1.32.0/2.3.0+, and you have to enable the token-audience checks. Why it matters: upgrading alone doesn't close the hole. https://www.mcpstore.nl/en/news/mcp-sdk-security-advisories/ and https://workos.com/blog/mcp-auth-bugs-trusting-the-other-side
  • Stateless MCP spec adoption is uneven: Claude Code uses it by default, Cursor only the older one. Support both revisions. https://9io.ai/blog/stateless-mcp-migration-guide
  • Google Cloud API Gateway now works as a remote MCP server, so existing REST APIs become agent tools without middleware. https://acceptallmag.com/story/turn-your-rest-apis-into-mcp-tools-with-google-cloud-api-gat-ee2118/
  • Framework release check: LangGraph 1.2.15, CrewAI 1.15.27, OpenAI Agents SDK 0.23.x (added MCP listing limits and Docker sandbox protection) and Google ADK 2.11.0 are steady releases. LlamaIndex is repositioning around document processing. CrewAI and OpenAI Agents need different major versions of openai, so use separate environments. https://dreaming.press/posts/ai-agent-frameworks-whats-changed-fall-2026.html and https://github.com/openai/openai-agents-python/releases/tag/v0.23.0
