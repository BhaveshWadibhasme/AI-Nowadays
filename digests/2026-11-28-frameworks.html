Agent frameworks roundup — week to 28 Nov 2026

Pydantic AI OpenAI Agents SDK Mastra CrewAI LangChain Google ADK LangGraph Claude Agent SDK Security Breaking changes

A patch-heavy week with a few real upgrade gotchas, mostly around sandboxes and browser tools.

Breaking changes & security

Security · Pydantic AI

Pydantic AI v2.74.0

Six medium advisories, mostly in the harness's PlaywrightBrowser: gaps in its private-address (SSRF) block via IPv6 site-local, NAT64 and backslash URLs, plus WebRTC egress and an OpenTelemetry leak. If your agents browse pages an attacker could influence, upgrade (pydantic-ai-harness 0.74.0+). The OTel fix is backported in v1.107.11.

v2.74.0https://github.com/pydantic/pydantic-ai/releases/tag/v2.74.0

Breaking · OpenAI Agents SDK

OpenAI Agents SDK v0.26.0

Docker sandboxes now reject in-container mounts (move to DockerVolumeMountStrategy), custom Realtime TraceProviders must report is_disabled(), and the Codex tool needs explicit approval for local images. An input-guardrail tripwire now stops queued tools. The separate 1.0 alpha.2 writes a new RunState format, so upgrade readers before writers.

v0.26.0https://github.com/openai/openai-agents-python/releases/tag/v0.26.0

Breaking · Mastra

Mastra core 1.86.0

get_process_output drops wait: true for waitSeconds, projectId becomes project in MCP apps components, and the playground trace components were reworked.

Releaseshttps://github.com/mastra-ai/mastra/releases

Security · CrewAI

CrewAI 1.15.45

Constant-time server auth, credentials dropped on cross-origin redirects, and a patched wcmatch dependency. Also new: save outputs as PDF artifacts.

1.15.45https://github.com/crewAIInc/crewAI/releases/tag/1.15.45

Breaking · LangChain

LangChain partner packages (23 Nov)

Python 3.10 was dropped across text-splitters, classic, Chroma, Qdrant, Ollama, Hugging Face and more, along with patches for vulnerable dependencies. Check your runtime before bumping.

Releaseshttps://github.com/langchain-ai/langchain/releases
