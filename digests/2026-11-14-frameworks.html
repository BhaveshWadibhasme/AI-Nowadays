Agent frameworks weekly roundup: 7–14 Nov 2026

LangChain LangGraph DSPy Agno A2A MCP Microsoft Agent Framework Pydantic AI Mastra LlamaIndex CrewAI Google ADK OpenAI Agents SDK Breaking changes Security

A busy week. Python 3.10 support is being dropped across the stack, A2A v1.0 is starting to show up in frameworks, and DSPy shipped a big release.

Breaking changes and security

Warning · LangChain

AI Engineering · Tools + agents

Python 3.10 dropped

LangChain 1.5.0, langchain-core 1.8.0 and langchain-openai 1.8.0 now require Python 3.11 or newer. Microsoft Agent Framework 1.25.0 does the same, and many LlamaIndex 0.14.26 integrations raised their minimum Python version to pick up security fixes. Check your bp project images before you upgrade.

LangChainhttps://github.com/langchain-ai/langchain/releases/tag/langchain%3D%3D1.5.0 MAFhttps://github.com/microsoft/agent-framework/releases/tag/python-1.25.0 LlamaIndexhttps://github.com/run-llama/llama_index/releases/tag/v0.14.26

Breaking · Agno

AI Engineering · Tools + agents

Agno 3.2

A2A moves to v1.0. The old /v1/message:* and /v1/tasks:* routes are gone, so upgrade servers and clients together. Slack approvals are now limited to the person who started the run unless you list other approvers=.

Releasehttps://github.com/agno-agi/agno/releases/tag/v3.2.0

Breaking · Microsoft Agent Framework

AI Engineering · Guardrails

Microsoft Agent Framework 1.26

Hyperlight sandbox code now stops after 30 seconds by default, and MCP discovery is capped (1.25).

Releasehttps://github.com/microsoft/agent-framework/releases/tag/python-1.26.0

Breaking · DSPy

AI Engineering · Measure

DSPy 3.5

XMLAdapter is now the default, which changes your prompts, and ReActV2 replaces ReAct. Re-run evaluations on any optimised programs. Disk caches now load in a restricted mode by default (a security hardening).

Releasehttps://github.com/stanfordnlp/dspy/releases/tag/3.5.0

Breaking · Mastra

AI Engineering · Tools + agents

Mastra core 1.83

The durable option now only controls resumable streams. For durable execution, switch to createDurableAgent.

Releasehttps://github.com/mastra-ai/mastra/releases/tag/%40mastra/core%401.83.0

Breaking · OpenAI Agents SDK

AI Engineering · Guardrails

OpenAI Agents SDK 0.24.0-alpha.7 (alpha)

The MCP approval modes are renamed (auto→native, approve→preapproved) and the default write policy is now strict.

Releasehttps://github.com/openai/openai-agents-python/releases/tag/v0.24.0-alpha.7

Security · LangChain

AI Engineering · Guardrails

Security fixes

langchain-core 1.7.7 caps how deeply load() will nest. LangGraph 1.2.21 bumps filelock and langgraph-api to pick up security fixes.

corehttps://github.com/langchain-ai/langchain/releases/tag/langchain-core%3D%3D1.7.7 LangGraphhttps://github.com/langchain-ai/langgraph/releases/tag/1.2.21

Worth knowing

LangChain

AI Engineering · Cost

LangChain 1.5

Adds a model router and an "auto mode" middleware (beta), plus new decision models in core. These are handy for routing between cheap and strong models to cut costs.

LangGraph

AI Engineering · Tools + agents

LangGraph 1.2.22

A batch of performance fixes, including faster Postgres checkpointing.

Releasehttps://github.com/langchain-ai/langgraph/releases/tag/1.2.22

Pydantic AI

AI Engineering · Guardrails

Pydantic AI 2.67–2.68

Falls back to the next model when output is cut off at max tokens, asks for approvals inside a run with RequestInput, and records guardrail verdicts durably.

Releasehttps://github.com/pydantic/pydantic-ai/releases/tag/v2.68.0

Mastra

AI Engineering · Guardrails

Mastra

A built-in MCP server at /api/mcp is on by default when auth is configured, so check what it exposes.

CrewAI

AI Engineering · Tools + agents

CrewAI 1.15.37–41

Agents can read spreadsheets, and crewai eval now runs headless.

Releaseshttps://github.com/crewAIInc/crewAI/releases

Google ADK

AI Engineering · Tools + agents

Google ADK 2.14

Sandboxes, A2A and evaluation are now stable, and evals can run multiple times per case.

Releasehttps://github.com/google/adk-python/releases/tag/v2.14.0

No notable releases this week for smolagents, the MCP spec or the A2A spec. The Claude Agent SDK only published version bumps without notes.

Hands-on

Worth trying

DSPy 3.5. The default install is now much smaller (about 31 MiB, down from 207 MiB) and imports twice as fast. RLM, GEPA and Flex are now stable too. Try GEPA prompt optimisation on one internal classification task and compare it against your hand-written prompt.

Upgrade guidehttps://dspy.ai/current/community/upgrading-to-3-5/
